# Security

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/Alien6-Studio/elea/security/advisories/new).
Do not include tokens, private keys, customer data or live endpoints in public
issues. Include the affected package and version and a synthetic reproduction.

The project is preparing its first public release. No stable support window is
claimed before that release. Rich text rendering must keep its HTML
sanitization and URL policy; any change to them is a security change.
