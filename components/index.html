UI integration

Add ELEA's React components to your app. Browse the component gallery.

Add a button

import { Button } from "@alien6-studio/elea-ui";
import "@alien6-studio/elea-ui/bundle.css";

export function DraftActions({ saveDraft }: { saveDraft: () => void }) {
  return <Button onClick={saveDraft}>Save draft</Button>;
}

This button inherits its outline from the active theme and uses its primary colour. Set variant="secondary" to give it a secondary role, or effect="ripple" to change its press gesture. Compare the same button across themes with Site theme in the header. Try Button states.

Use the UI and tokens packages at the same version. The UI bundle loads both stylesheets.

For a checkout, build the npm archives with npm run check -- --pack-destination artifacts. Run npm install in your app with the paths to both the UI and tokens .tgz files.

Theme

Browse the colour atlas to explore each theme’s photography and colour scales. The themes set the palette, typography, spacing and control shapes. Reading surfaces are white and light grey, with neutral greys in dark mode. Adjust the theme and download its CSS in Theme Studio.

Load the downloaded stylesheet after the UI bundle, then set data-elea-theme="brand" on your app container. See how themes reach dialogs, sheets and toasts.

Tailwind and shadcn/ui

With Tailwind v4, import the bundle in your main stylesheet and declare the layer order. This keeps Preflight below the components and lets utilities override them.

@layer theme, base, elea, components, utilities;
@import "tailwindcss";
@import "@alien6-studio/elea-ui/bundle.css";

Add @alien6-studio/elea-tokens/theme.css to use ELEA's tokens in Tailwind utilities. See the Tailwind v3 setup and shadcn/ui integration.

One sheet per component

For smaller stylesheets, load the tokens once and import the styles for each component you use.

@import "@alien6-studio/elea-tokens/elea.css";
@import "@alien6-studio/elea-ui/css/button.css";

See the stylesheet reference for shared sheets and form control refs.

Motion

Set data-elea-motion="on" on a container to enable expressive motion. It respects the visitor's reduced-motion setting. If you import individual sheets, add @alien6-studio/elea-ui/css/motion.css. Try the Expressive motion switch in the gallery.

Footer

The site uses ELEA's Footer component. See the Footer example for passing your own brand, link groups and signature.
